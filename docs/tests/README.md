# Tests

## Overview

The `tests` folder contains unit and integration tests for the research agent, including evaluators, pairwise evaluations, prompts, and scripts for running evaluations.

Key files:
- `evaluators.py`: Defines evaluation functions.
- `pairwise_evaluation.py`: Handles pairwise comparisons.
- `prompts.py`: Test-specific prompts.
- `run_evaluate.py`: Script to run evaluations.
- `supervisor_parallel_evaluation.py`: Parallel evaluation for supervisors.

## Purpose

These tests ensure the reliability of the agent's components, such as research quality, model outputs, and workflow integrity.

## Connections

Tests interact with the core and legacy implementations to validate functionality.
