# Open Deep Research Reasoner Documentation

## Overview

Open Deep Research is an open-source deep research agent designed to conduct comprehensive research on given topics using language models and search tools. It leverages LangGraph for workflow management and supports various configurations for models, search APIs, and research parameters.

The project is structured into current implementation (`src/open_deep_research`), legacy code (`src/legacy`), security features (`src/security`), tests, and examples.

## Project Structure

- **src/open_deep_research**: Core implementation of the deep researcher agent.
- **src/legacy**: Older multi-agent and graph-based implementations.
- **src/security**: Authentication and authorization using Supabase.
- **tests**: Unit and integration tests.
- **examples**: Jupyter notebooks demonstrating usage.
