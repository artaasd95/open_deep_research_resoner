# Examples

## Overview

The `examples` folder contains Jupyter notebooks and markdown files demonstrating usage of the deep research agent.

Key examples:
- `arxiv.md`: Demonstrates research on ArXiv topics.
- `inference-market-gpt45.md`: Example using GPT-4.5 for inference market research.
- `inference-market.md`: General inference market research example.
- `pubmed.md`: Shows research using PubMed search.

## Purpose

These examples illustrate how to configure and run the agent for specific research tasks, integrating with different search APIs.

## Connections

Examples use the core implementation in `src/open_deep_research` and can be used for testing and learning.
